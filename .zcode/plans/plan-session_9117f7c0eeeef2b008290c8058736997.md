# Tkinter 桌面应用替换方案

## 核心设计思路

**直接调用后端模块，不走 HTTP**。Tkinter 应用直接 `import` 后端 M1-M9 的 Python 模块，省去 HTTP 中间层，更简单更快。

## 文件结构

```
backend/app/gui/
├── __init__.py
├── app.py          # 主窗口 + 启动入口（~500行）
├── pages.py        # 三个标签页：分析/历史/设置（~400行）
└── widgets.py      # 可复用组件：评分面板/建议列表/缺陷面板（~200行）
```

## 技术要点

| 功能 | Tkinter 实现方式 |
|------|-----------------|
| 标签页切换 | `ttk.Notebook` |
| 代码输入/对比 | `tk.Text` + `ScrolledText`（双栏） |
| 评分圆环 | `tk.Canvas` 绘制弧形 |
| 维度进度条 | `ttk.Progressbar` |
| 建议列表 | `ttk.Treeview` + 按钮 |
| 缺陷列表 | `ttk.Treeview`（可展开） |
| 历史表格 | `ttk.Treeview` |
| 供应商列表 | `tk.Listbox` |
| 表单输入 | `ttk.Entry` / `ttk.Combobox` |
| 分析线程 | `threading.Thread` 避免界面卡顿 |
| 状态提示 | `ttk.Progressbar` + `Label` |

## 启动方式

```bash
# 直接运行 GUI（无需启动后端服务器）
python backend/app/gui/app.py
```

## 不需要修改的部分

- 后端 M1-M9 所有服务模块保持不变
- LLM 供应商配置存储（JSON文件）保持不变
- 训练模块保持不变

只需新增 3 个 GUI 文件即可。
